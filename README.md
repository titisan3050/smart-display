# Smart Display

Android タブレットをスマートディスプレイ化する、HTML 1 枚のダッシュボード。

- 日替わりの名言
- 日付・時計（ネットワーク状態 / バッテリー残量）
- 天気（Open-Meteo）
- アプリランチャー / 内蔵タイマー
- Google ニュース（時事 / 車 / ガジェット）

## 使い方

1. タブレットの Chrome で GitHub Pages の URL を開く
2. メニュー →「ホーム画面に追加」
3. 右上のボタンで全画面表示

## 設定

`index.html` 冒頭の設定欄で変更できます。

- `LOCATION` … 天気の地点（地名・緯度・経度）
- `APPS` … ランチャーのアプリ
- `FEEDS` … ニュースのカテゴリ
- `TAB_ROTATE_SEC` … ニュースタブの自動切替秒数（0 で無効）
