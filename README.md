# Smart Display

Android タブレットをスマートディスプレイ化する、HTML 1 枚のダッシュボード。

- 日替わりの名言
- 日付・時計（ネットワーク状態 / バッテリー残量）
- 天気（Open-Meteo）
- アプリランチャー / 内蔵タイマー
- Google ニュース（時事 / 車 / ガジェット、カテゴリ追加可）
- 現在地マップ（ニュース欄と切替。カーナビ風に移動をリアルタイム表示）

## 使い方

1. タブレットの Chrome で GitHub Pages の URL を開く
2. メニュー →「ホーム画面に追加」
3. 右上のボタンで全画面表示

## 設定

`index.html` 冒頭の設定欄で変更できます。

- `DEFAULT_LOCATION` … 天気の地点の初期値（画面の天気カードをタップして変更することもできます）
- `APPS` … ランチャーのアプリ
- `DEFAULT_FEEDS` … ニュースカテゴリの初期値（画面のタブ右端の「＋」から追加・削除・並べ替えもできます）
- `TAB_ROTATE_SEC` … ニュースタブの自動切替秒数（0 で無効）

## 個人設定の保存

画面で変更した地域・ニュースカテゴリ・表示中のパネル（ニュース / マップ）は、ブラウザの localStorage に保存されます。端末（ブラウザ）ごとに独立していて、サーバーには送信されません。
